# 🏫 教室座位分配优化系统 (Classroom Seat Allocation)

> 基于 Python 与 SCIP 求解器的 0-1 整数规划项目。在满足 13 项硬性约束的前提下，为 12 名学生分配座位，最大化全体学生的满意度总和。

---

## 📖 一、项目背景

某班级有 12 名学生（编号 A ~ L），教室共有 4 排 5 列，共 20 个座位。

### 1.1 物理座位布局
- **靠窗列**：第 1 列、第 5 列
- **靠过道列**：第 2 列、第 4 列
- **中间列**：第 3 列
- **相邻定义**：左右相邻（同排、列差 1）或前后相邻（同列、排差 1）

### 1.2 数据说明
- **排偏好**：学生 i 对第 r 排的喜爱程度（1~5分）。
- **列偏好**：学生 i 对第 c 列的喜爱程度（1~5分）。
- **单座满意度**：若学生 i 坐在第 r 排第 c 列，其满意度为排偏好 + 列偏好。

---

## 📐 二、数学模型（核心解题逻辑）

### 2.1 符号定义
- 学生集合 \(S = \{A, B, C, \dots, L\}\)
- 排集合 \(R = \{1, 2, 3, 4\}\)
- 列集合 \(C = \{1, 2, 3, 4, 5\}\)

### 2.2 决策变量
定义 0-1 决策变量 \(x_{i,r,c}\)：
- \(x_{i,r,c} = 1\)：学生 i 坐在第 r 排第 c 列
- \(x_{i,r,c} = 0\)：否则

### 2.3 目标函数
最大化所有学生的总满意度：
$$\max \sum_{i \in S} \sum_{r \in R} \sum_{c \in C} (P_{i,r} + Q_{i,c}) \cdot x_{i,r,c}$$
其中 \(P_{i,r}\) 为排偏好分，\(Q_{i,c}\) 为列偏好分。

### 2.4 硬性约束条件（分类详解）

#### 🔹 唯一性与容量约束
1. **每人一座**：\(\sum_{r \in R} \sum_{c \in C} x_{i,r,c} = 1\)，对所有学生 \(i\) 成立。
2. **每座一人**：\(\sum_{i \in S} x_{i,r,c} \le 1\)，对所有排 \(r\) 和列 \(c\) 成立。
3. **单排上限**：\(\sum_{i \in S} \sum_{c \in C} x_{i,r,c} \le 4\)，对所有排 \(r\) 成立（每排最多 4 人）。
4. **第二排下限**：\(\sum_{i \in S} \sum_{c \in C} x_{i,2,c} \ge 3\)，即第二排至少坐 3 人。

#### 🔹 特殊学生位置约束
5. **A、B 视力较差**：必须坐在前两排（第 1 排或第 2 排）。
6. **C 个子较矮**：必须坐在第 1 排。
7. **H 必须靠窗**：列号必须为 1 或 5。
8. **I 必须靠过道**：列号必须为 2 或 4。
9. **L 坐后排**：必须坐在第 3 排或第 4 排。

#### 🔹 人际关系与冲突约束
10. **D、E 左右相邻**：引入辅助变量强制锁定这两个座位。
11. **F、G 不能相邻**：不能左右相邻，也不能前后相邻。
12. **J、K 同排不相邻**：两人在同一排，但列号差的绝对值不能为 1。

#### 🔹 互斥约束
13. **A、C 不同列**：两人的列号不能相等。
14. **B、L 不同排**：两人的排号不能相等。

## 📂 三、项目结构（工程化规范）

本项目采用标准 Python `src` 布局，实现了逻辑与数据的解耦：

- **src/**
  - **seat_allocation/**
    - `__init__.py`：包声明
    - `data.py`：数据层（存放偏好分、学生名单、物理列定义）
    - `model.py`：逻辑层（SCIP 模型构建：变量、目标、约束）
    - `solver.py`：输出层（调用求解器并打印座位表）
- **tests/**
  - `test_allocation.py`：测试模块（校验变量数量与约束）
- `main.py`：入口程序（运行本项目）
- `README.md`：项目说明文档
- `LICENSE`：开源许可证 (MIT License)
- `requirements.txt`：依赖清单
- `.gitignore`：Git 忽略规则

## 🚀 四、快速开始

### 4.1 环境依赖
- Python 3.10+
- PySCIPOpt (SCIP 求解器的 Python 接口)

### 4.2 安装与运行
1. 安装依赖：
   `pip install -r requirements.txt`
2. 运行求解程序：
   `python main.py`

### 4.3 运行输出示例
```text
开始构建模型...
模型构建完毕，开始求解...

第3排: [J] [G] [.] [.] [K]
```
